Colour

Each energy source owns one hue: Solar = amber, Battery = teal, Grid = electric blue, Home = ink. Fills are for marks and lines. Text uses the darker "ink" step. Colour always comes with an icon and a label.

Accessibility

Contrast. All text is 4.5:1 or better (WCAG AA). Fills like amber only carry dark ink text (8.7:1). Never colour alone. Nodes carry an icon, a name and a value. Offline is a dashed outline plus "!" and the word "Offline". Toggles show a check. Screen readers. Each flow node is a button with a full sentence, e.g. "Battery: 64%, charging at 2.1 kW". Reduced motion. Flows stop and stay as solid lines with arrows. Counters jump straight to the final value. RTL. Layout mirrors: battery and solar swap sides, progress and switches run right-to-left. Numerals stay Western (0–9), as most UAE apps do.

Voice & copy

Say what it means"Enough to run about 3 ACs" next to 5.4 kW. kWh always comes with a comparison.
Lead with the human result"82% powered by the sun", not "Self-consumption ratio 0.82".
Name every change"Pause until 7 pm · still 80% by 7 am". No hidden automation.
Reward, never guilt"Not this time", "Your streak is paused, not lost", "You keep the points earned so far".
Write for both languagesShort sentences that translate cleanly. Arabic copy is written fresh, not word for word.
