# MEGAMAX International Trading — Sparrow Mark

Open `index.html` in a browser for the concept board (reference analysis, construction, three concepts, scale test, colour).

| File | Use |
| --- | --- |
| `megamax-mark-ink.svg` | Mono mark, black |
